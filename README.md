```The soX tool — this tool uses a brute-force attack on login links to gain access to the admin or site owner's account. I built this tool because I was practicing hacking and I found a hidden admin panel link, but I didn't have the username and password to log in, so that's why I created this tool.
soX.py Argument Guide

-u, --url

Target login endpoint.

-l, --userlist

Path to username dictionary.

-p, --passlist

Path to password dictionary.

-x, --proxylist

Path to proxy list (optional).
```
